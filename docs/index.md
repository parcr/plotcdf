# plotcdf

plotcdf provides utilities to model and visualize discrete random variables.

The package validates support/probability inputs and generates:

- Probability mass function (PMF) plots
- Cumulative distribution function (CDF) plots
- Quantile function plots

## Why use it

- Strong input validation for support, probabilities, tails, and tolerance
- PMF/CDF conversion helpers
- Configurable Matplotlib styles for plot elements
- Plot methods return `(figure, axes)` so you can keep customizing

## Install

```bash
pip install plotcdf
```
