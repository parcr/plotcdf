PlotCDF
^^^^^^^^^^^^
PlotCDF provides utilities to model and visualize discrete random variables.
The package supports PMF, CDF, and quantile plots.

Installation
^^^^^^^^^^^^^^
.. code-block:: bash

	pip install plotcdf
